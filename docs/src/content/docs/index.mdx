## Your Architecture, Live Inside IntelliJ IDEA

ArcDrift turns your codebase into an interactive, always-up-to-date **C4 architecture canvas** directly inside IntelliJ IDEA. Instead of drawing static diagrams that go stale the next day, you can inspect real dependencies, enforce package boundaries, verify REST/Kafka contracts across languages, and hand off architectural violations to your local or cloud AI model.

## What You Can Do with ArcDrift

<CardGrid stagger>
  <Card title="Explore Live C4 Diagrams" icon="puzzle">
    Zoom seamlessly from high-level package containers (**C4 L2**) down to controllers, services, repositories, and API clients (**C4 L3**) or individual DTOs and methods (**C4 L4**).
  </Card>
  <Card title="Catch Polyglot Contract Breaks" icon="random">
    Spot route typos, missing endpoints, and DTO field mismatches (including `@JsonProperty` and `@SerialName` wire aliases and cross-file DTO imports) between TypeScript (`fetch` / `axios`), Python (`FastAPI` / `requests` / `httpx`), and Kotlin/Java (`@RestController` / Ktor) before you run your app.
  </Card>
  <Card title="Refactor & Self-Heal in One Click" icon="rocket">
    Extract interfaces with **Extract Port**, sketch planned components with **+ Ghost Component**, or click **Handoff to Agent** to let your AI model repair violations and prove compliance.
  </Card>
  <Card title="Block Drift in Pull Requests" icon="approve-check-circle">
    Keep rules in a Git-friendly `architecture.arc.mmd` Mermaid file, run `arc check` and `arc diff` in CI, post visual blast-radius PR comments, and generate JUnit 5 `ArchUnit` tests.
  </Card>
</CardGrid>
