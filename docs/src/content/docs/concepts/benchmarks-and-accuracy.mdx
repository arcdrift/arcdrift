title: Benchmarks & Accuracy
description: Empirical evaluation of ArcDrift across 10 real-world open-source repositories, controlled contract mutations, and MCP context-slice token reduction.
---

To prevent upstream repository changes from skewing regression measurements, every release of ArcDrift is evaluated against **fixed, pinned commits of 10 real-world open-source repositories** spanning Java Spring Boot, Spring WebFlux, Kotlin Spring Boot, Python FastAPI, Angular, Vue, React TypeScript, OpenAPI 3, and TypeSpec (`*.tsp`).

---

## Controlled Mutation Recall (`8 / 8 = 100%`)

To verify detection recall on breaking changes that compile cleanly in isolation, the benchmark suite injects 8 controlled mutations across `jhipster-sample-app-react` (`M1` — `M7`) and `full-stack-fastapi-template` (`M8`):

| Mutation | Description | Detected? |
| :--- | :--- | :--- |
| **`M1`** | Rename `/api/operations` $\rightarrow$ `/api/operationz` in `OperationResource.java` | Caught (`Route contract mismatch`) |
| **`M2`** | Rename response DTO field `description` $\rightarrow$ `details` in `OperationDTO.java` | Caught (`DTO field mismatch`) |
| **`M3`** | Rename response DTO field `amount` $\rightarrow$ `totalAmount` in `OperationDTO.java` | Caught (`DTO field mismatch`) |
| **`M4`** | Rename `/api/bank-accounts` $\rightarrow$ `/api/bank-accountz` in `BankAccountResource.java` | Caught (`Route contract mismatch`) |
| **`M5`** | Rename `/api/labels` $\rightarrow$ `/api/tags` in `LabelResource.java` | Caught (`Route contract mismatch`) |
| **`M6`** | Remove `GET /api/account` endpoint in `AccountResource.java` | Caught (`Unresolved REST contract`) |
| **`M7`** | Rename `@RequestBody` field `newPassword` $\rightarrow$ `updatedPassword` in `PasswordChangeDTO.java` | Caught (`@RequestBody field mismatch`) |
| **`M8`** | Rename Pydantic `ItemCreate` request-body field `title` $\rightarrow$ `heading` in FastAPI `models.py` | Caught (`@RequestBody field mismatch`) |
