Different engineering questions require different levels of detail. When onboarding a teammate or reviewing module boundaries, seeing every helper class and DTO is overwhelming; when debugging a broken REST endpoint, you need to see the exact controller and client.

ArcDrift lets you switch your view of the same codebase across **four C4 zoom levels** using the dropdown in the top toolbar.

---

## C4 Semantic Zoom Levels

| C4 Level | Toolbar Option | When to Use It | What You See |
| :--- | :--- | :--- | :--- |
| **`L1_SYSTEM`** | *System Context* | High-level system boundary overview (via MCP / CLI slices). | Top-level `SYSTEM` boundary and external dependencies. |
| **`L2_CONTAINER`** | **`C4 L2: Containers & Packages`** | Reviewing package modularity, layer dependencies, and package-level rule violations. | High-level `PACKAGE` containers, `MODULE`s, and top-level frontend clients (`TS_CLIENT`, `PYTHON_CONSUMER`). Dependencies and violations from classes inside each package roll up automatically to their parent package container. |
| **`L3_COMPONENT`** | **`C4 L3: Components & Contracts`** | *(Default)* Day-to-day architecture review, REST/Kafka contract verification, and port extraction. | Architectural components (`REST_CONTROLLER`, `SERVICE_BEAN`, `REPOSITORY`, `MESSAGE_LISTENER`, `INTERFACE`, `GHOST_SPEC`, `TS_CLIENT`, `PYTHON_CONSUMER`) with their exposed/consumed routes and violation callouts. |
| **`L4_CODE`** | **`C4 L4: Classes & Code`** | Deep-diving into data models, DTOs, entities, and implementation classes. | Every class in the module, including `DATA_CLASS` DTOs, `ENTITY` models, `ENUM`s, and utility `CLASS`es. |

## Filtering, Searching & Arranging the Canvas

- **Search by Name or `@Stereotype`:** Type into the **`Filter component or @Stereotype...`** box in the toolbar to filter the canvas in real time (for example, type `@RestController`, `Order`, or `com.acme.repo`).
- **Isolate Violations & Diffs:** Click **`Filter: All Components`** (or click the **`⛔ N Violations`** status pill on the right) to switch to **`Filter: Diffs & Violations`**, hiding all clean, unchanged components so you can focus strictly on what needs attention.
- **Drag to Pin & Grid Snap:** Toggle **`Grid Snap: On (20px)`** for crisp alignment when dragging cards. Any card you drag is pinned at its new position across live code edits until you click **`Auto-Layout`**.
