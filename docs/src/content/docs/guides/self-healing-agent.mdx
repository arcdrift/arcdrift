When ArcDrift detects a boundary violation, circular dependency, or broken REST contract — or when you sketch a new **Ghost Component** on the canvas — you can hand the task directly to the built-in **Self-Healing Agent Workspace** for 1-click contract and boundary auto-repair.

The Agent Workspace works with any OpenAI-compatible server, including **`llama-swap`**, **`llama.cpp` (`llama-server`)**, **Ollama**, **LM Studio**, **vLLM**, and **OpenAI**. If you prefer to use an external AI coding assistant (such as Claude Code, Cursor, or JetBrains Junie), you can connect it to the [`arc mcp` server](/reference/mcp-server-tools/) instead.

## Step-by-Step: Running an Architectural Task

<Steps>

1. **Click `Handoff to Agent` in the Toolbar**

   ArcDrift opens the **Agent Workspace** on the right side of the canvas and automatically populates the **Architectural Task Prompt** with:
   - All active boundary and REST contract violations
   - Any circular dependency edges that need to be broken
   - Any planned `GHOST_SPEC` components waiting to be implemented

2. **Choose Your Endpoint & Model**

   - **OpenAI API Base URL:** Defaults to `http://localhost:11434` (or `OPENAI_BASE_URL` / `OPENAI_API_BASE`). If you enter a bare host without a path (such as `http://localhost:11434`), ArcDrift appends `/v1` automatically; any explicit path (`/v1`, `/v1beta/openai`, `/api/paas/v4`) is preserved verbatim before appending `/models` and `/chat/completions`.
   - **Model ID & `Fetch Models`:** Click **Fetch Models** to query all models available on your server and select one from the dropdown (or set `OPENAI_MODEL`).
   - **Max Turns:** Defaults to `30` (adjustable from `1` to `100`).
   - **API Key (optional):** Leave blank for local servers (`llama-swap`, Ollama, LM Studio) or enter your Bearer key for remote providers.

3. **Click `▶ Run Self-Healing Agent`**

   During the run, you can watch each turn in real time:
   - The agent queries your architecture graph (`get_architecture_slice`), reads relevant files (`read_project_file`), applies deterministic refactorings (`execute_deterministic_refactoring`) or targeted edits (`write_project_file`), and runs `verify_architectural_compliance` to prove all violations are resolved.
   - You can stop a run at any time by clicking **`■ Stop Agent`**.

4. **Navigate to Modified Files via File Chips**

   Click any file chip in the tool call cards or the final Markdown summary:
   - **TypeScript (`TS` / `TSX`):** Opens `.ts` / `.tsx` files (e.g., `ordersClient.ts`)
   - **Kotlin (`KT`) & Java (`J`):** Opens `.kt` / `.java` classes at the exact line (e.g., `OrderController.kt`)
   - **Python (`PY`):** Opens `.py` consumers
   - **Architecture Spec (`ARC`):** Clicking `architecture.arc.mmd` (or `.arc.mmd`) opens your primary `architecture.arc.mmd` specification file in the editor and highlights it in the Project Explorer.

</Steps>

<Aside type="tip" title="Automatic Model Fallback on Local Servers">
  If you type a shorthand model name or if a model configured in `llama-swap` fails to start on Turn 1, ArcDrift automatically matches or falls back to a working model on your endpoint and updates your saved Model ID.
</Aside>
